# 系统升级方案

> 版本：0.0.1（草案）
> 日期：2026-10-20
> 目标机器：Lenovo Legion Y7000P IRH8
> 当前系统：Ubuntu 26.10 / GNOME Shell 51 / Wayland / Kernel 7.3.0-9
> 文档状态：待评审，未执行
> 核心原则：稳定优先、操作可逆、只用官方源、分阶段验证

---

## 1. 背景与目标

当前系统整体健康，但存在几处明确可优化点：

- RTX 4060 仍由 `nouveau` 驱动，独显能力未利用；
- `geoclue.service` 每次启动超时 90 秒，系统长期处于 degraded；
- Apache 监听 80 端口但启动以来 0 请求，CUPS 无打印机，ModemManager 无 WWAN；
- 595GB ext4 分区未挂载，149GB swap 分区未启用；
- 防火墙未开启，且没有系统级备份；
- 16GB 内存同时运行 Qoder、Trae CN、Firefox，内存偏紧。

本方案目标：

1. 消除启动故障和无用服务；
2. 让闲置磁盘可用，并建立可回滚的系统备份；
3. 在不牺牲稳定性的前提下启用独立显卡；
4. 所有改动都有明确回滚路径。

本方案**不是**极限性能调优方案，不追求跑分，不修改分区表，不刷固件，不关闭内核安全缓解。

## 3. 总体原则与非目标

### 3.1 原则

1. **先停后禁**：任何服务先 `stop` 观察，确认无影响后再 `disable`。
2. **先备份后改动**：改 `fstab`、`grub` 前先备份；装驱动前先有 Timeshift 快照。
3. **一次只改一类东西**：NVIDIA 驱动单独安排一次，不同时改内核参数、主题、扩展。
4. **只用官方源**：Ubuntu 官方仓库 + Flathub stable；不添加 PPA，不使用“一键优化脚本”。
5. **可逆优先**：每个操作都必须能在一条命令内回退。
6. **不碰分区表和固件**：除非出现明确故障，否则不调整分区、不刷 BIOS。

### 3.2 非目标

- 不启用休眠；
- 不调整 149GB swap 分区；
- 不刷 BIOS；
- 不关闭内核安全缓解（`mitigations=off` 等）；
- 不安装第三方内核或非官方显卡驱动；
- 不追求“零启动进程”式精简。

## 4. 风险分级

| 措施 | 收益 | 风险 | 可逆性 | 结论 |
|---|---|---|---|---|
| 备份 `fstab` / `grub` | 高 | 无 | 不适用 | 必做 |
| 停用 Apache/CUPS/ModemManager | 中 | 低 | `systemctl start` | 先停后禁 |
| 开启 UFW | 中 | 低 | `ufw disable` | 做 |
| 挂载 `/data` | 高 | 低 | 删除 fstab 行 | 做，加 `nofail` |
| 启用 zram | 中 | 低 | 停服务/卸载包 | 做 |
| Timeshift 快照 | 高 | 无 | 不适用 | 必做 |
| geoclue 超时限制 | 中 | 低 | 删除 drop-in | 做 |
| 电池保养模式 | 低 | 低 | 写回 0 | 按使用习惯决定 |
| NVIDIA 580 驱动 | 高 | 中 | `prime-select intel` / 卸载 | 单独窗口执行 |
| 修改 `noatime` / `swappiness` | 低 | 低 | 改回默认 | 可跳过 |

## 5. 分阶段执行

### 阶段 0：准备（无系统改动）

目标：保留当前状态，确认需求边界。

```bash
sudo cp /etc/fstab /etc/fstab.bak.$(date +%F)
sudo cp /etc/default/grub /etc/default/grub.bak.$(date +%F)

systemctl --failed
systemd-analyze
free -h
df -hT
```

需要先确认的问题见第 9 节。确认完成前，不执行阶段 3。

---

### 阶段 1：低风险、无需重启（全部可逆）

#### 1.1 停止无用服务（先不永久禁用）

```bash
sudo systemctl stop apache2 cups cups.socket cups-browsed ModemManager
```

判断依据：

- Apache 监听 `*:80`，默认页面，启动以来 0 请求；
- `lpstat -p` 无打印机；
- 机器无 WWAN 模块。

验证：

```bash
ss -tln
systemctl status apache2 cups ModemManager --no-pager
```

如果某服务报 “Unit not found”，不影响其他服务停止。

#### 1.2 开启 UFW

```bash
sudo ufw default deny incoming
sudo ufw default allow outgoing
sudo ufw enable
sudo ufw status verbose
```

注意：

- UFW 只影响入站，不影响浏览器和普通上网；
- 如果需要用手机访问本机开发服务器，先确认端口，再单独放行；
- 启用前建议先执行 `ss -tln` 记录实际监听端口。

#### 1.3 挂载 595GB 数据分区

先临时挂载并检查旧数据：

```bash
sudo mkdir -p /data
sudo mount /dev/sda4 /data
sudo ls -la /data
```

确认无重要旧数据后，写入 fstab：

```bash
echo 'UUID=8ed8dd81-aee1-4727-80f4-c62583469b00 /data ext4 defaults,nofail 0 2' | sudo tee -a /etc/fstab
sudo umount /data
sudo mount -a
sudo chown $USER:$USER /data
findmnt /data
```

说明：

- `nofail` 保证磁盘异常时不影响开机；
- 不要执行 `chown -R`，避免误改旧数据权限；
- 如果 `ls` 发现旧数据，先备份再决定是否继续。

#### 1.4 启用 zram

```bash
sudo apt install -y zram-tools
sudo sed -i 's/^#\?ALGO=.*/ALGO=zstd/; s/^#\?PERCENT=.*/PERCENT=50/' /etc/default/zramswap
sudo systemctl restart zramswap
zramctl
```

说明：

- 使用 zstd，压缩内存约为物理内存的 50%；
- 此阶段不改 `vm.swappiness`，保持系统默认，观察稳定性；
- 如不需要，可 `sudo systemctl disable --now zramswap` 后卸载。

#### 1.5 安装 Timeshift 并创建首个快照

```bash
sudo apt install -y timeshift
```

GUI 配置建议：

- 模式：RSYNC；
- 目标：`/data`；
- 频率：每周一次；
- 保留：3–5 个快照；
- 排除：`/data`（避免快照递归），`/home` 是否包含按需选择；
- 个人文件另行使用 Deja Dup、Syncthing 或 rclone 备份。

完成首个快照后，才能进入阶段 3。

#### 1.6 可选：零风险桌面调整

```bash
gsettings set org.gnome.desktop.interface show-battery-percentage true
gsettings set org.gnome.desktop.interface clock-show-seconds true
gsettings set org.gnome.desktop.interface color-scheme 'prefer-dark'
```

CLI 别名（可选）：

```bash
echo "alias bat='batcat'
alias fd='fdfind'" >> ~/.bashrc
```

### 阶段 2：观察 3–7 天后固化

前提：阶段 1 期间没有发现打印、局域网访问、Apache 相关需求。

#### 2.1 永久禁用无用服务

```bash
sudo systemctl disable apache2 cups cups.socket cups-browsed ModemManager
```

如需恢复：

```bash
sudo systemctl enable --now apache2 cups cups.socket cups-browsed ModemManager
```

#### 2.2 处理 geoclue 启动超时

保守做法：只限制超时，不删除服务。

```bash
sudo mkdir -p /etc/systemd/system/geoclue.service.d
sudo tee /etc/systemd/system/geoclue.service.d/timeout.conf >/dev/null <<'EOF'
[Service]
TimeoutStartSec=10
EOF
sudo systemctl daemon-reload
```

重启后检查：

```bash
systemd-analyze
systemctl --failed
```

如果确认完全不用定位服务，可进一步屏蔽：

```bash
sudo systemctl mask --now geoclue.service
```

#### 2.3 可选：电池保养模式

适合长期插电使用；经常外出用电池则不建议开启。

```bash
echo 1 | sudo tee /sys/bus/platform/drivers/ideapad_acpi/VPC2004:00/conservation_mode
```

关闭：

```bash
echo 0 | sudo tee /sys/bus/platform/drivers/ideapad_acpi/VPC2004:00/conservation_mode
```

如需开机自动生效，再添加 systemd oneshot 服务；在确认使用习惯前不固化。

#### 2.4 可选：按需安装软件

只装当前需要的，不一次性铺开。建议优先级：

1. 备份与系统工具：`timeshift`（已装）、`btop`、`duf`、`ncdu`；
2. 开发工具：`build-essential`、`pkg-config`、`cmake`、`ripgrep`、`fd-find`、`fzf`；
3. 字体：`fonts-jetbrains-mono`、`fonts-noto-color-emoji`；
4. 其他按实际需求安装，避免扩大更新面。

---

### 阶段 3：NVIDIA 驱动（单独执行）

#### 3.1 前置条件

- [ ] 阶段 1 的 Timeshift 首个快照已完成；
- [ ] 当前没有正在进行的系统升级；
- [ ] 机器已接通电源；
- [ ] 有一段可以重启和排查问题的时间；
- [ ] 已了解 TTY 恢复方式。

#### 3.2 安装

```bash
sudo apt update
sudo ubuntu-drivers install nvidia:580
sudo reboot
```

说明：

- 选择 580 而不是 615，优先成熟度；
- `ubuntu-drivers` 会安装当前内核对应的预编译模块，减少 DKMS 编译风险；
- 本阶段不同时修改 GRUB，不添加 `preempt=full`，不安装第三方内核模块。

#### 3.3 验证

```bash
nvidia-smi
prime-select query
```

笔记本建议按需使用独显：

```bash
sudo prime-select on-demand
```

切换后注销并重新登录。

#### 3.4 回滚

如果出现登录循环、黑屏或 Wayland 异常：

```bash
# Ctrl+Alt+F3 进入 TTY
sudo prime-select intel
sudo systemctl restart gdm
```

如果仍然异常：

```bash
sudo apt purge '^nvidia-.*'
sudo apt autoremove
sudo update-initramfs -u
sudo reboot
```

有 Timeshift 快照时，也可从 live USB 启动恢复。

#### 3.5 判断是否值得做

| 使用场景 | 建议 |
|---|---|
| CUDA、AI 推理、游戏、视频硬解、外接显示器性能 | 执行阶段 3 |
| 只浏览网页、写文档、轻量开发 | 可保持 nouveau，系统更省心 |
| 对稳定性要求极高 | 暂不执行，等有明确需求再做 |

## 6. 暂缓 / 不做清单

以下项目不进入 0.0.1 执行范围：

1. 刷 BIOS：`fwupd` 显示无更新，固件日期 2023-07；除非出现风扇、睡眠、独显切换故障，否则不刷。
2. 休眠：混合显卡 + zram + 大 swap 的失败模式较多，继续使用 suspend。
3. 调整 149GB swap 分区：涉及分区操作，收益低，风险高。
4. 根分区改 `noatime`、`vfs_cache_pressure=50`：收益很小，保持默认。
5. `preempt=full`、`mitigations=off`、第三方内核参数：不引入额外变量。
6. 大量 GNOME 扩展和第三方主题：GNOME 51 较新，扩展是 shell 崩溃的主要原因；最多保留 2–3 个，不强制启用不兼容版本。
7. 第三方 PPA、“一键优化”脚本、非官方驱动源。
8. LenovoLegionLinux 等第三方内核模块：等有明确风扇/功耗需求时再评估。

## 7. 回滚手册

| 操作 | 回滚方式 |
|---|---|
| 停止 Apache/CUPS/ModemManager | `sudo systemctl start apache2 cups cups.socket cups-browsed ModemManager` |
| 禁用上述服务 | `sudo systemctl enable --now apache2 cups cups.socket cups-browsed ModemManager` |
| 开启 UFW | `sudo ufw disable` |
| 挂载 `/data` | 删除 `/etc/fstab` 中对应行，`sudo umount /data` |
| 启用 zram | `sudo systemctl disable --now zramswap`，必要时卸载 `zram-tools` |
| geoclue 超时限制 | 删除 `/etc/systemd/system/geoclue.service.d/timeout.conf`，`sudo systemctl daemon-reload` |
| 屏蔽 geoclue | `sudo systemctl unmask geoclue.service` |
| 电池保养模式 | `echo 0 | sudo tee /sys/bus/platform/drivers/ideapad_acpi/VPC2004:00/conservation_mode` |
| NVIDIA 驱动 | `sudo prime-select intel`；或按 3.4 节卸载 |
| fstab 改坏 | `sudo cp /etc/fstab.bak.YYYY-MM-DD /etc/fstab` |
